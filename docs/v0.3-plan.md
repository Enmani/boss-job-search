# v0.3

范围：Ashby、Lever、通用岗位导入、批量筛选排序与独立设置页。

- 平台读取器只向官方 GET 接口发送请求，使用严格身份校验、超时与响应大小限制。各公司失败分别返回，不把失败变成空结果。Lever 区分 global/EU。
- 沿用当前 JSON 岗位与 SQLite v2 结构。旧岗位身份和进度不变；手工导入保留原文与明确来源，任意链接只保存、不自动抓取。
- Codex 提取批量原文上下文并做语义判断；批量结论以事务保存，拒绝过期版本和虚构引用。面板按硬条件与已保存结论排序，不以关键词命中替代能力判断。未知和过期分别展示。
- 设置页使用同一面板服务与认证。四个平台卡片并排，公开接口显示配置与实际检测结果。目标公司、基础偏好和默认简历移入设置，首页保留任务操作。
- 每个代码文件小于 500 行；MCP 与面板复用业务动作。面板不增加任意文件读取、系统命令或投递接口。
- 验收覆盖源接口转换/失败、旧数据和进度保留、批量事务/引用/排序、设置与导入真实按钮，以及浅深主题、窄屏和放大显示。
- 发布前完成真实 Ashby、Lever、Greenhouse、BOSS 搜索和详情，实际手工导入、Codex 语义批量保存与排序、进度在重启后的保存。私有验证记录不进入仓库或发布包。
